Introduction:

This document is a high level explanation of the software requirements and is intended 
to be a basis for the robo sub project. There is no specific target audience for this 
SRS and it is designed for any team working on or wanting to know more abou the Robo Sub.
The software will utilize many different technologies and frameworks, and its primary goal 
is for a more efficient and reliable software for the robosub

Description:

The RoboSub software will directly attempt to solve challenges of efficiency, user access, and
automation. Issues that may need solving include: Improving computer vision, addressing unorganized 
repo strucutre and dependencies, and ensuring compatability with newer technologies. The team will be
divided into subteams, including a autonomy team, controls team, computer vision team, and team lead 
to help organize the project. The Robosub is designed as a AUV (Autonomous underwater vechicle), and 
will have main functions such as Navigation and control, Computer vision, and Simulation that need to 
work simultaniously to in order to function properly. The Operating environment will be on a Nvidia 
Graphics card using a linux distro. 


External Interface Requirements:

The RoboSub software will need to connect with multiple user, hardware, software, and communication 
interfaces. The main user interfaces include the project website and the simulation GUI. The website 
gives users access to project information, while the simulation interface allows the team to view and 
test the submarine in a virtual pool environment. The hardware interfaces include a microcontroller, 
thrusters, and actuators. the Microcontroller helps communicate with sensors and actuators. The 
software also connects communication between subsystems.


Requirements Specification:

The system has several main functional requirements. The computer vision system must capture visual input, 
process the video feed, and identify important objects in the environment. The information from the vision 
system should then be converted into useful data that can help guide the vehicle during operation.The 
navigation and control system must manage the vehicle's movement and communicate with the necessary onboard 
components. It should be able to send movement commands, adjust direction, and support autonomous behavior. 
The simulation system must allow the team to test the vehicle in a virtual environment before using real 
hardware. The website must display general project information, team information, sponsor information, 
media, procedures, and progress updates.


Other Nonfunctinoal Requirements:

No outstanding requirements to be fufilled outside of time and task completion, focus will mainly be on the 
Robosub to operate autonomously and perform tasks reliably. Safety is taken into consideration, with indepth
testing being done to ensure thruster safety, waterproofing of any electronics, and electrical safety. 

Legal and Ethical Considerations:

The project should be developed in a responsible and honest way. team must clearly state what information came 
from the original project. This helps avoid misrepresenting the work as fully original. The team should also 
respect intellectual property by giving credit to any outside resources, documents, diagrams, code, or design 
ideas that are referenced. Any copied or adapted material should be cited or rewritten in the team’s own words.
